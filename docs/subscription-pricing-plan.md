# サブスクリプション料金設計書

## ICP（理想の顧客像）

| 項目 | 内容 |
|---|---|
| ターゲット | 人材紹介会社・企業の採用担当者 |
| 企業規模 | 従業員10〜500名（中小〜中堅） |
| 課題の深刻度 | 高（求人原稿の質が応募数に直結する） |
| 利用頻度 | 月2〜20回（企業規模・採用ボリュームで大差） |

---

## 料金モデル：基本料金 + 従量課金

```
月額基本料金：¥3,000（固定）
  └ 含まれるもの：アカウント利用権、ダッシュボード、履歴閲覧

従量課金：使った分だけ
  ├ Team A（新規原稿作成）：¥800 / 回
  ├ Team B（原稿改善）：¥400 / 回
  └ サムネイル再生成（単体）：¥200 / 回（将来オプション）
```

### 原価と粗利

| 機能 | 単価 | 原価 | 粗利 | 粗利率 |
|---|---|---|---|---|
| Team A | ¥800 | ~¥340 | ¥460 | 57% |
| Team B | ¥400 | ~¥150 | ¥250 | 63% |

## 3プラン構成（ボリュームディスカウント）

| | スターター | スタンダード | プロ |
|---|---|---|---|
| **月額基本料金** | ¥3,000 | ¥9,800 | ¥29,800 |
| **含まれるクレジット** | 0回 | Team A×10回分 | Team A×40回分 |
| | | (¥8,000相当) | (¥32,000相当) |
| **超過時の単価** | A: ¥800 / B: ¥400 | A: ¥700 / B: ¥350 | A: ¥600 / B: ¥300 |
| **割引率** | なし | 12%OFF | 25%OFF |
| **想定ターゲット** | 小規模・お試し | 中堅企業 | 大量採用企業 |
| **ユーザー数** | 1名 | 5名まで | 無制限 |

### プラン設計のポイント

- スタンダード以上はクレジット込みで「使わないと損」感を出し、利用を促進
- プロプランはボリュームディスカウントで大口顧客を囲い込む

## 競争力の検証

### 顧客視点のROI（スタンダードプランの場合）

```
月額コスト：¥9,800 + 超過分 ≒ ¥10,500/月

得られる価値：
  - 求人原稿作成の外注相場：1媒体 ¥30,000〜50,000
  - 本ツールで4媒体同時生成：¥800/回
  - 月5回利用で ¥4,000（外注なら ¥150,000〜250,000）

顧客のROI：15〜25倍
```

外注やライターに依頼する費用と比べて圧倒的にコスパが良いため、導入障壁は低い。

## 実装面で必要になるもの

| 必要なもの | 方法 |
|---|---|
| 利用回数のカウント | DB（Supabase）にTeam A/B実行ログを記録（既存機能） |
| 課金・決済 | Stripe Billing（従量課金対応） |
| プラン管理 | Stripe Products + Supabase のユーザーテーブル |
| 利用状況ダッシュボード | フロントエンドに「今月の利用回数・残クレジット」表示 |
| 請求書発行 | Stripe Invoice（自動） |

## 備考

- 料金は2026年4月時点のClaude API料金（Opus: $15/$75、Sonnet: $3/$15、Haiku: $0.80/$4 per 1M tokens）に基づく概算
- 為替レートは $1 = ¥150 で計算
- 原稿執筆（Team A）とテキスト改善（Team B）はClaude Opus、その他エージェントはSonnet/Haikuを使用
- サムネイル生成はGemini APIを使用
