# new-posting 3ステップウィザード化 設計書

日付: 2026-07-23
対象: `app/components/forms/JobInputForm.tsx` / `app/components/forms/AIInputMode.tsx`

## 背景と目的

現在の new-posting 画面は「AIかんたん入力（テキスト・URL・ファイル混在）」と「フォーム入力」の2モード切替。これを、入力方法を最初に選んでから順に進む3ステップのウィザードに再構成する。

- ステップ1: 入力方法の選択（「求人情報を自分で入力」「求人のURLを貼り付ける」「PDFなどのファイルを添付」）
- ステップ2: 選んだ方法で情報を入力
- ステップ3: サムネ生成の素材になる画像を登録（任意）→ 生成実行

## 画面構成

1. **ステップインジケータ**（常時表示）: ①入力方法 → ②情報を入力 → ③サムネ素材と生成。完了済みステップはクリックで戻れる。
2. **出力媒体の選択カード**（常時表示・現状踏襲）: どのステップでも変更可能。
3. **ステップ本体**:

### ステップ1: 入力方法の選択

3枚のカードから1つ選ぶと自動でステップ2へ進む。

| 選択肢 | ステップ2の内容 |
|---|---|
| 求人情報を自分で入力 | フリーテキスト欄（AI解析）。「詳細フォームで入力」への切替トグル付き |
| 求人のURLを貼り付ける | URL入力欄（ペーストで自動追加・複数可） |
| PDFなどのファイルを添付 | ドラッグ&ドロップのファイル添付（PDF・画像・テキスト） |

### ステップ2: 情報入力

- 「自分で入力」はフリーテキスト⇄詳細フォーム（既存のタブ式: 共通情報+媒体別）をトグルで切替。
- 「次へ」ボタンは入力があるときのみ有効（フリーテキスト=本文あり / URL=リストまたは入力欄に有効URL / ファイル=1件以上。詳細フォームは常に可）。
- 「戻る」でステップ1へ。

### ステップ3: サムネ素材と生成

- 既存の「サムネイル参考画像」UIをここに移動（文言は「サムネ生成の素材になる画像（任意）」）。
- 生成ボタン:
  - 詳細フォーム経由: 「AIで求人原稿を自動生成」→ 従来どおり直接 progress へ。
  - フリーテキスト / URL / ファイル経由: 「AIで解析して原稿を作成」→ `/api/parse-job-input` を選択方法に応じたペイロードで呼び、解析結果をマージして progress へ。
- 解析エラーはこの画面に表示し、「入力方法を『自分で入力』に切り替えて本文を貼り付ける」誘導を添える。

## コンポーネント構成の変更

- `AIInputMode.tsx`: 解析ボタン・API呼び出しを持つモノリスから、**制御されたフィールド群 `AIInputFields`** に再構成。`method`（text / url / file）に応じた入力UIのみを描画し、状態は親が保持する（`AIInputValue = { text, urlInput, urls, files }`）。`parseValidUrl` と型を export。
- `JobInputForm.tsx`: ウィザードの状態（step / method / manualVariant / aiInput / isParsing / parseError）と解析API呼び出しを持つ。既存の `handleAIParsed`（マージ→sessionStorage→progress 遷移）は流用。

## 既存挙動の維持

- 既存求人の流用（`initialData` あり）は、ステップ2の「詳細フォーム」を開いた状態で開始する。
- 媒体未選択時の生成ブロック、サムネ参考画像の圧縮アップロード、解析中の入力保全（`formDataRef`）は現状踏襲。
- `/api/parse-job-input` は変更しない。

## スコープ外

- progress 画面・生成パイプラインの変更
- 複数枚のサムネ素材対応（現行どおり1枚）
