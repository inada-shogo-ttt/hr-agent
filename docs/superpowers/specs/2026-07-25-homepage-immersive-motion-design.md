# トップページ・没入型アニメーション設計

## 目的

公開トップページのコピー、情報構造、CTA、レスポンシブ構造を維持しながら、ページ全体を「求人情報の入力→媒体別原稿の作成→掲載結果から改善」という一本の採用フローとして動かす。スクロール、ポインター操作、視差、段階的な状態変化を組み合わせ、印象に残るリッチなサイトへ更新する。

本設計は `2026-07-19-homepage-animation-design.md` の方向性を引き継ぎ、演出強度を「印象重視」へ引き上げた実装仕様とする。

## 方針

- 採用フロー型を主軸にし、没入感のある背景と強いインタラクションを組み合わせる
- デスクトップでは大胆なパララックス、3Dチルト、連続モーションを使用する
- モバイルではフェード、ズーム、順次表示を中心に軽量化する
- アニメーションは製品理解を助ける用途に限定し、コピーとCTAの可読性を損なわない
- コーラルピンク、白、チャコール、編集コラージュ画像という既存の世界観を維持する
- 外部アニメーションライブラリは追加しない

## 体験の流れ

### ヘッダー

- 画面上端にページ全体のスクロール進捗線を表示する
- スクロール開始後はヘッダーを固定し、半透明背景、ブラー、薄いシャドウを加える
- ヘッダー高とロゴをわずかに縮小し、本文領域を広く見せる

### ヒーロー

- タグライン、見出し、本文、CTA、機能要約を大きな時間差で段階表示する
- 背景のグラデーションメッシュと装飾光をポインター位置に追従させる
- 右の管理画面デモに大きめの3Dチルトと緩やかな浮遊を加える
- デモ内のステップ、入力欄、AI生成領域、プレビューを順番に強調し、作業の流れを表現する
- 主CTAはポインターを引き寄せる軽い磁力効果と周期的なシマーを持つ

### 課題カード

- セクション表示時に4枚を斜め方向から連続して出現させる
- ホバー時はカードとコラージュ画像が異なる奥行きで浮上する
- ポインター位置に沿って、紙面上を移動する柔らかな光沢を表示する

### PRODUCT

- 説明、注釈、編集画面、媒体一覧を異なる方向と速度で表示する
- 入力欄、生成ボタン、媒体ステップを順番に点灯する
- 入力情報から4媒体へ伸びる光の流れを表示し、媒体カードを段階的に完了状態へ変える
- 既存の4カラム構造を維持し、演出によるレイアウトシフトを発生させない

### 3ステップ

- スクロールに合わせてカード間の接続線を左から右へ描画する
- 番号、コラージュ画像、カード境界を順番に強調する
- 完了したカードはわずかに持ち上がり、次のカードへ視線を誘導する

### FEATURES

- 暗背景に大きなポインター追従スポットライトを表示する
- カードは奥行きのある3Dチルトと境界光を持つ
- コラージュ画像はカードと異なる速度で移動し、紙片が浮いているように見せる
- 表示時はカードが下から連続してせり上がる

### 対応媒体

- 4媒体カードを複製表示し、途切れない横方向マーキーにする
- ホバー、キーボードフォーカス、タッチ操作時は自動移動を停止する
- 各カードのホバー時は前面へ拡大し、他カードの移動を弱める

### 活用例

- カード、写真、本文を異なる速度で表示し、重なりのある編集紙面のように見せる
- デスクトップでは写真に視差、カード全体に3Dチルトを加える
- モバイルではカード表示と写真ズームだけに簡略化する

### 最終CTA

- コーラル背景の光とグラデーションをゆっくり移動させる
- 見出し、本文、チャコールボタン、UI装飾を順番に表示する
- ボタン上を周期的な光が横切る
- 既存のボタン色、リンク先、コピーは維持する

## コンポーネント設計

### `app/components/home/RichMotion.tsx`

- ページ全体のスクロール進捗、ヘッダー状態、ポインター座標、視差量を管理する
- スクロールとポインターのDOM反映は `requestAnimationFrame` でまとめる
- 値はCSSカスタムプロパティとして公開し、各セクションが再レンダリングなしで参照する
- fine pointer環境でのみポインター追従を有効化する

### `app/components/home/Reveal.tsx`

- 表示方向、距離、回転、拡大率、遅延、表示時間を指定できるよう拡張する
- Intersection Observerで一度だけ起動し、表示後は監視を解除する
- JavaScriptが利用できない場合も内容を読める構造を維持する

### `app/components/home/TiltCard.tsx`

- ポインター位置からカードの回転、子要素の奥行き、光沢位置を計算する
- 最大角度を制限し、pointerleaveとfocusoutで確実に初期状態へ戻す
- タッチ端末とreduced motion環境では静的コンテナとして動作する

### `app/components/home/FlowSequence.tsx`

- PRODUCTと3ステップの順次点灯、接続線、完了状態を管理する
- セクションが表示領域へ入ったときだけ一度起動する
- 演出状態は装飾に限定し、本文やリンクの状態を変更しない

### `app/page.tsx`

- 既存セクションへ各モーションコンポーネントと演出用データ属性を適用する
- コピー、画像、CTA遷移、見出し階層、レスポンシブ構造は変更しない

### `app/globals.css`

- 背景メッシュ、シマー、マーキー、接続線、紙の浮遊、スポットライト、縮小ヘッダーのスタイルを定義する
- transformとopacityを中心にし、レイアウト再計算を起こすアニメーションを避ける

## パフォーマンス

- スクロールイベントはpassive listenerとrequestAnimationFrameで処理する
- ポインター追従はfine pointerかつデスクトップ幅でのみ有効にする
- Intersection Observerで画面外のシーケンスを開始しない
- transform、opacity、CSSカスタムプロパティを中心に更新する
- 画像は既存のNext Image最適化を維持する
- モバイルでは3Dチルト、ポインター追従、大きな視差を停止する

## アクセシビリティ

- `prefers-reduced-motion: reduce`ではマーキー、3Dチルト、視差、シマー、自動進行を停止する
- reduced motion時はすべての内容を最初から表示する
- フォーカス中の媒体マーキーを停止する
- アニメーション中もリンク、ボタン、フォーカスリング、読み上げ順を維持する
- 進捗線、光、接続線などの装飾要素は支援技術から隠す

## 失敗時の扱い

- Intersection Observerが利用できない場合は内容を即時表示する
- requestAnimationFrame処理に依存せず、初期HTMLだけで全情報とCTAを利用できる
- ポインター座標が取得できない環境では中央位置の静的背景として表示する
- アニメーション用状態が解除されてもレイアウトやリンク機能へ影響しない

## 検証

1. `npm run build`が成功する
2. 1440px、1024px、390px幅で横スクロール、重なり、レイアウトシフトがない
3. キーボードだけですべてのリンクとボタンを操作できる
4. 媒体マーキーがホバーとフォーカスで停止する
5. reduced motion環境で自動移動と視差が停止し、全内容が即時表示される
6. デスクトップでスクロール進捗、3Dチルト、パララックス、各シーケンスが動作する
7. CTAのリンク先、コピー、既存画像、セクション順序に変更がない

## 成功条件

- ページ全体に連続した動きと強い奥行きがある
- 入力、媒体別原稿作成、掲載後改善の流れをアニメーションから理解できる
- デスクトップでは印象に残る大胆な体験になる
- モバイル、reduced motion、キーボード操作で可読性と操作性を損なわない
- 新しいランタイム依存を追加しない
