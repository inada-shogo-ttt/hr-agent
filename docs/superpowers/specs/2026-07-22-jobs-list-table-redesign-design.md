# 求人管理ページ テーブル型リニューアル 設計書

日付: 2026-07-22
対象: `/jobs`（求人管理・事業所一覧ページ）

## 背景と目的

現在の `/jobs` は事業所ごとの2カラムカードグリッドで、表示情報が「職種名・求人数・原稿あり件数」に限られている。運用上、原稿の作成状況や掲載媒体・更新日を一覧で把握したいニーズがあり、検索・並び替え・新規求人作成の導線も不足している。

ブレインストで3案（リッチカード / ワイドリスト / テーブル）を比較し、**テーブル型（管理画面型）** を採用した。

## 画面構成

`app/jobs/page.tsx` を全面改修する。

1. **ヘッダー**: タイトル「求人管理」+ 説明文（現状踏襲）。右端に「＋ 新規求人作成」ボタン（rose 系のプライマリボタン）。
2. **ツールバー**: 検索ボックス1つ。事業所名・職種名に対する部分一致で行を絞り込む（入力即時反映、クライアント側処理）。
3. **テーブル**: 列は以下の6列。

| 列 | 内容 | ソート |
|---|---|---|
| 事業所 | 事業所名（太字） | ○（名前順） |
| 職種 | 職種ごとの件数チップを上位2つ + 「ほかN職種」 | − |
| 求人数 | 事業所内の求人件数（右寄せ） | ○ |
| 原稿 | `原稿あり数/求人数` バッジ。全件完了=緑、未作成残あり=rose | ○（未作成数順） |
| 媒体 | 各求人の最新レコードの platform を重複排除しバッジ表示 | − |
| 更新日 | 事業所内求人の `updatedAt` 最新値（M/D 表記） | ○（初期: 降順） |

4. **行クリック**で `/jobs/offices/[officeId]` へ遷移（現状のカードクリックと同じ）。
5. **コンテナ幅**: `max-w-4xl` → `max-w-5xl` に拡大。テーブルは `overflow-x-auto` のラッパーで包み、モバイルは横スクロールで対応。

## データと集計

- **API 変更なし**。既存 `GET /api/jobs` のレスポンス（Job + officeName / jobTypeName / employmentTypeName / records[最新1件] / updatedAt）をそのまま使う。
- フロントの `JobEntry` インターフェースに `updatedAt: string` を追加（API は既に返している）。
- officeId ごとのグループ化を拡張し、以下を集計する:
  - `jobTypeCounts`: 職種名 → 件数の配列（件数降順）
  - `manuscriptCount` / `jobs.length`: 原稿進捗
  - `platforms`: `records[0].platform` の distinct
  - `lastUpdatedAt`: `updatedAt` の最大値

## 並び替え・検索の挙動

- 状態は `sortKey`（`name | jobCount | manuscript | updatedAt`）と `sortDir`（`asc | desc`）で管理。初期値は `updatedAt` の降順。
- ソート可能列の見出しクリックで、同一列なら昇順/降順トグル、別列なら降順（名前のみ昇順）で切り替え。見出しに矢印アイコンで現在のソート状態を表示。
- 検索・ソートはすべてクライアント側で行う（事業所数は多くて数十件想定のため）。

## 新規求人作成の導線

1. 「＋ 新規求人作成」クリックで事業所を選ぶ小ダイアログ（既存 `Dialog` + `Select` を使用）を開く。
2. 事業所を選んで決定すると `/jobs/offices/[officeId]?add=1` へ遷移。
3. `app/jobs/offices/[officeId]/page.tsx` に「クエリ `add=1` が付いていたら既存の『職種を追加』ダイアログを初期表示で開く」処理を追加する（変更はこの1点のみ）。

## ローディング・エラー・空状態

- ローディング: テーブル型のスケルトン（ヘッダー行 + プレースホルダ行数行）に差し替え。
- エラー / 事業所ゼロ件: 現状の `Card` + アイコン + メッセージ表示を踏襲。
- 検索結果ゼロ件: テーブル領域に「該当する事業所がありません」の1行表示。

## 変更ファイル

- `app/jobs/page.tsx` — 本体の全面改修
- `app/jobs/offices/[officeId]/page.tsx` — `?add=1` での追加ダイアログ自動オープンのみ
- `components/ui/table.tsx` — shadcn/ui の Table を追加（npm 依存の追加はなし）

## スコープ外

- API・DB スキーマの変更
- 絞り込みフィルタ（職種別・原稿有無別など）
- 事業所詳細ページ（`/jobs/offices/[officeId]`）自体のデザイン変更
