# トップページ・リッチアニメーション設計

## 目的

公開トップページの情報構造とコピーを維持しながら、スクロール、ポインター操作、UIデモの状態変化を使った洗練されたSaaS向けアニメーションを追加する。装飾だけでなく、求人情報の入力、媒体別原稿の作成、掲載後の改善という製品フローを動きで理解できるページにする。

## デザイン方針

- 方向性は「洗練されたSaaS演出」とする。
- コーラルピンク、白、チャコールの既存配色を維持する。
- ページ全体に動きを加えるが、主要コピーとCTAの可読性を優先する。
- アニメーションはユーザー操作を妨げず、レイアウトシフトを発生させない。
- 外部アニメーションライブラリは追加せず、CSS、Intersection Observer、requestAnimationFrameを中心に実装する。

## 演出構成

### ヘッダー

- ページ上端にスクロール進捗バーを表示する。
- スクロール後は背景を半透明化し、ブラーと薄いシャドウを加える。
- ヘッダー高とロゴをわずかに縮小し、本文領域を広く保つ。

### ヒーロー

- タグライン、見出し、本文、CTA、機能要約を順番に表示する。
- 背景のグラデーションメッシュと装飾光をポインター位置に応じて緩やかに移動させる。
- 管理画面デモに奥行きのある3Dチルトを追加する。
- デモ内ではステップ、入力項目、AI生成領域、生成結果を時間差で強調し、処理の流れを表現する。
- CTAにはホバー時の矢印移動と周期的なシマーを加える。

### 課題カード

- セクション表示時にカードを左から順番に出現させる。
- ホバー時は浮上、境界色変化、ポインター追従の光沢を表示する。
- タッチ端末ではホバー専用演出を無効化する。

### PRODUCT

- 説明、機能注釈、編集画面、媒体一覧を異なる方向から表示する。
- 編集画面内の入力欄、AI生成ボタン、媒体ステップを順番に点灯させる。
- 媒体カードは原稿生成完了を示すチェック状態へ段階的に変化させる。
- 既存の4カラム構造を維持し、アニメーション要素を絶対配置で重ねない。

### 3ステップ

- セクションの表示に合わせてカード間の接続線を左から右へ伸ばす。
- 各カードは未処理から完了へ変化し、アイコンと番号を順番に強調する。
- 文章を読む速度を妨げない時間差にする。

### 機能セクション

- ダーク背景にポインター追従スポットライトを表示する。
- カードは軽い3Dチルトと境界光を持つ。
- アイコンは表示時に線が描かれるようなスケール・透明度アニメーションを行う。

### 対応媒体

- 4媒体カードを連続的に流すマーキー演出にする。
- ポインターが乗った場合は移動を停止する。
- キーボードフォーカス時も停止し、媒体名を読みやすく保つ。

### 活用例

- カード表示時に写真と本文を時間差で表示する。
- デスクトップでは写真に軽い視差移動、カードに3Dチルトを加える。
- モバイルでは画像ズームのみの軽量演出に置き換える。

### 最終CTA

- 背景の光とグラデーションをゆっくり移動させる。
- CTAボタンに周期的なシマーを加える。
- CTAが画面に入った際は、見出し、本文、ボタン、UI装飾を順番に表示する。

## コンポーネント設計

- `app/components/home/RichMotion.tsx`
  - スクロール進捗、ヘッダー状態、ポインター座標を管理するクライアントコンポーネント。
  - DOM更新はrequestAnimationFrameでまとめる。
- `app/components/home/Reveal.tsx`
  - 表示方向、遅延、距離、スケールを指定できるよう拡張する。
  - Intersection Observerは一度表示したら解除する。
- `app/components/home/TiltCard.tsx`
  - ポインター位置から回転角度と光沢位置を計算する。
  - 最大角度を小さく制限し、pointerleaveで元に戻す。
- `app/page.tsx`
  - 既存セクションに演出用クラスとコンポーネントを適用する。
  - 製品コピー、画像、CTA遷移、レスポンシブ構造は変更しない。
- `app/globals.css`
  - キーフレーム、マーキー、シマー、スポットライト、縮小ヘッダー、リビール方向を定義する。

## パフォーマンス

- スクロールイベントはpassive listenerとrequestAnimationFrameで処理する。
- transformとopacityを中心に使用し、レイアウト計算を繰り返すプロパティは避ける。
- ポインター追従はデスクトップのfine pointer環境だけで有効化する。
- Intersection Observerで画面外の演出処理を開始しない。
- 生成済み画像は現在のNext Image最適化を維持する。

## アクセシビリティ

- `prefers-reduced-motion: reduce`ではマーキー、3Dチルト、視差、シマー、自動進行を停止する。
- reduced motion時はコンテンツを最初から表示する。
- アニメーション中もフォーカス位置、リンク、ボタンの操作を維持する。
- 装飾要素は支援技術から隠す。

## レスポンシブ

- デスクトップでは全演出を有効化する。
- タブレットではチルト角度と視差量を抑える。
- モバイルではポインター追従、3Dチルト、複雑な視差を停止し、フェード、スライド、画像ズームへ置き換える。
- どの画面幅でも横スクロールを発生させない。

## 検証

- `npm run build`で型・本番ビルドを確認する。
- 1440px、1024px、390px幅で重なりと横スクロールがないことを確認する。
- キーボード操作中にマーキーや装飾が可読性を損なわないことを確認する。
- reduced motion環境ですべての情報が即時表示されることを確認する。
- アニメーション前後でCTAのリンク先と既存機能に差分がないことを確認する。

## 成功条件

- ページ全体に一貫した動きと奥行きがある。
- 製品フローをアニメーションから理解できる。
- コピーの可読性、CTA操作、モバイル表示を損なわない。
- reduced motionとキーボード操作に対応する。
- 新しいランタイム依存を追加しない。
