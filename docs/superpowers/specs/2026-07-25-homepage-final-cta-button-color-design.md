# トップページ 最終CTAボタン配色修正設計

## 目的

トップページ下部の「最初の求人原稿を作成する」CTA帯で、右側の白いボタンが背景から浮いて見える状態を修正する。

## 設計

- 対象は `app/page.tsx` の最終CTA帯にある「求人原稿を作成する」ボタンのみ
- ボタン背景を濃いチャコール `#252a30` にする
- ボタン文字と矢印は白にする
- ホバー時はチャコールを少し明るくし、操作可能であることを伝える
- 既存の角丸、寸法、配置、リンク先、コピーは変更しない
- ピンクのCTA帯との十分なコントラストを保つ

## 比較した案

- 白: 明るく見えるが、ユーザーが指摘した現在の状態を解消しない
- コーラルピンク: ブランド色には合うが、CTA帯の背景と同化する
- 濃いチャコール: 背景と明確に分離し、ページの本文色とも整合するため採用

## 検証

- 通常時とホバー時に白文字が読みやすい
- ボタンのサイズや配置が変わらない
- `npm run build` が成功する
