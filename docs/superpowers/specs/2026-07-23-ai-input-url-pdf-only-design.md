# AIかんたん入力: URL貼り付け・PDF添付だけで求人作成 設計書

日付: 2026-07-23
対象: `app/components/forms/AIInputMode.tsx`（new-posting 画面の AIかんたん入力モード）

## 背景と目的

AIかんたん入力モードは `/api/parse-job-input`（テキスト・URL・PDF・画像対応）に接続済みで、解析後はそのまま Team A の原稿生成が始まる。しかし UI 上は次の問題があり、「URLだけ・PDFだけで作成できる」体験になっていない。

1. URL欄に貼り付けただけ（「追加」ボタン未クリック）の URL は解析対象に含まれず、他の入力がなければ解析ボタンも押せない。
2. テキスト欄が必須に見え、URL単体・PDF単体で良いことが画面から伝わらない。

トリガーは**ワンクリック型**を採用する（貼り付け・添付でボタンが有効になり、ボタン1回で解析→原稿生成まで進む）。完全自動起動は誤操作時に生成コストが走るため採用しない。

## 変更内容

### 1. URL貼り付けだけで動くように

- URL入力欄への**ペースト時、貼り付けた文字列が有効なURLなら自動でリストに追加**し、入力欄をクリアする（「追加」ボタン不要）。
- 手入力等で入力欄に残ったままの有効URLは、**解析実行時に自動でリストへ取り込んで**解析対象に含める（重複は除外）。
- 解析ボタンの有効判定 `hasInput` に「URL入力欄に有効なURLがある状態」を追加する。

### 2. PDF添付だけで動くように

- 機能変更なし（添付のみでボタンが有効になる既存挙動を維持）。案内文で明示する。

### 3. 文言の変更

- 冒頭説明: 「求人ページのURLを貼るだけ、求人票PDFを添付するだけでもOK」を明記。
- テキスト欄ラベル: 「求人情報を入力」→「求人情報を入力（任意）」。
- 解析ボタン: 「AIで自動解析する」→「AIで解析して原稿を作成」（解析後そのまま生成が始まる実態に合わせる）。

## 変更しないもの

- `/api/parse-job-input`（既にURL・PDF単体入力に対応済み）
- `JobInputForm.tsx` の解析後フロー（`handleAIParsed` → progress 遷移）
- 媒体選択・サムネイル参考画像・エラー時のフォールバック文言

## スコープ外

- 貼り付け・添付を検知した瞬間の自動解析（完全自動型）
- URL取得方法（Jina Reader / 直接fetch）の改善
